# portfolio

Single-page portfolio, laid out like a component datasheet: features, block diagram,
characteristics with conditions, figures, revision history. Plain HTML, CSS and
JavaScript, no build step, no framework, no tracking.

```
python3 -m http.server 8000     # then open http://localhost:8000
python3 scripts/sync_activity.py   # refresh the git activity + revision history
```

## What is where

| | |
|---|---|
| `index.html` | All the copy. Every number carries a provenance tag (`CHIP`, `HOST`, `PROJ`, `EXACT`, `SIM`, `LIVE`). |
| `assets/style.css` | Tokens (light + dark), layout, components. |
| `assets/js/anc-core.js` | LMS / ADALINE port of `tinys/adalineDemo/src/adalineDemo/reference.py`. Checked against it: max abs difference 2.9e-8 over 4,000 samples (16 taps, 8 kHz, lr 0.004). |
| `assets/js/kalman-core.js` | Port of `sentinel-core`'s `KalmanFilterFrugal` and `sentinel-sim`'s trajectories. |
| `assets/js/charts.js` | Tiny SVG chart helpers (scales, axes, tooltip, resize). |
| `assets/js/demos.js` | The RAM figure, the four live demos, activity lanes, change log. |
| `data/directconv.js`, `media/directconv/` | directConv's video lab (five scenarios, three videos each), rendered by `scripts/render_directconv.py` with directConv itself; see below. |
| `data/activity.js` | Generated by `scripts/sync_activity.py` from the git logs of frugal_ml, ferrite-embedded, directConv, adalineDemo, sentinel and Classifhear. Don't edit by hand. |
| `assets/fonts/` | Archivo and IBM Plex (latin subset, woff2), served from this repo so the page makes no third-party request. SIL Open Font License 1.1, texts alongside. |

## directConv's video lab

```
../../tinys/directConv/.venv/bin/python scripts/render_directconv.py CLIP.mp4
```

Drives `directConv.demo.runner` exactly as the lab page does (`run`, then `play` per scenario),
copies the three videos per scenario into `media/directconv/` re-encoded at CRF 32, and writes
the measured and projected numbers to `data/directconv.js`. Run it from a scratch directory: the
runner caches downloads in `./data/videos`.

The clip is a 10 s 720p excerpt of *Big Buck Bunny*, © 2008 Blender Foundation,
peach.blender.org, licensed CC BY 3.0 (https://creativecommons.org/licenses/by/3.0/); the
attribution is shown under the videos. imageio's `cockatoo.mp4`, the lab's default, is not
used here because its licence isn't documented.
